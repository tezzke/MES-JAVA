# Modbus TCP 单设备现场调试

## 1. 用途与边界

“系统管理 → Modbus 现场探针”用于新设备接入前的只读验收，不修改正式
`devices.json`，也不复用正式采集连接。接口只支持功能码 `03`（保持寄存器）和
`04`（输入寄存器），每次读取最多 125 个寄存器，禁止任何写功能码。

只有拥有 `MODBUS_PROBE` 权限的用户可见并可调用该功能。系统迁移会把权限赋给
内置 `ADMIN` 角色；给其他角色授权时应遵循最小权限原则。

## 2. 启用

该功能默认关闭。按现场设备网段设置环境变量后重启后端：

```text
MES_MODBUS_PROBE_ENABLED=true
MES_MODBUS_PROBE_ALLOWED_CIDRS=192.168.10.0/24
MES_MODBUS_PROBE_ALLOWED_PORTS=502
MES_MODBUS_PROBE_MAX_CONCURRENT=2
```

- `ALLOWED_CIDRS` 支持逗号分隔的 IPv4/IPv6 CIDR；不要配置 `0.0.0.0/0`。
- `ALLOWED_PORTS` 支持逗号分隔，通常只保留 `502`。
- 域名的全部解析结果都必须在白名单内，连接时使用校验后的固定 IP，防止 DNS
  重绑定。Loopback 和 link-local 地址始终拒绝。
- Linux 离线部署在 `/opt/mes/config/mes.env` 设置同名变量，再执行
  `/opt/mes/current/linux/upgrade.sh --skip-backup` 重建容器。

调试结束后把 `MES_MODBUS_PROBE_ENABLED` 改回 `false` 并重启。

## 3. 单次验收

1. 用有权限的账号登录，进入“系统管理 → Modbus 现场探针”。
2. 填写设备 IP、端口、Unit ID、功能码、起始地址和寄存器数量。
3. 先执行“测试连接”；成功只表示 TCP 端口可连接，不代表点位参数正确。
4. 选择数据类型、寄存器内字节序、32 位跨寄存器字序、缩放和偏移，执行“单次读取”。
5. 对照设备手册检查请求/响应 Hex、逐寄存器 Hex/十进制、原始解析值和缩放值。

地址按 Modbus PDU 的零基地址发送。若设备手册写 `40001`，常见对应起始地址 `0`，
但不同厂商标法可能不同，必须以设备通讯手册为准。

## 4. 短时轮询与导出

轮询间隔限制为 100–10000 ms，会话最长 60 秒；后端默认最多同时运行 2 个会话。
页面关闭、路由切换或点击停止时会主动终止会话，后端也会按时限自动停止。

验收时建议：

1. 先用单次读取确认参数；
2. 用 1000 ms 间隔运行 10–30 秒；
3. 操作设备使目标值变化；
4. 导出 JSON 保存完整结构，导出 CSV 交给工艺或设备供应商签字确认；
5. 记录设备型号、固件、点位手册版本、网络参数和导出文件 SHA-256。

## 5. 错误定位

- `403`：账号缺少 `MODBUS_PROBE`，或目标 IP/端口不在白名单。
- `429`：并发探针已达上限，停止已有轮询后重试。
- `TIMEOUT`：检查路由/VLAN、防火墙、设备在线状态和超时设置。
- `CONNECTION_REFUSED`：目标主机可达但端口未监听。
- `MODBUS_EXCEPTION`：设备返回异常码，重点核对功能码、Unit ID 和地址范围。
- `PROTOCOL`：响应事务号、协议号、功能码或长度不符合 Modbus TCP。

探针返回错误时不会自动改用写命令，也不会绕过网络白名单。
